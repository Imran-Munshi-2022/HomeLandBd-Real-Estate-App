## ✨ Key Features
* **User Authentication:** Secure Welcome, Login, and Registration screens with validation.
* **Home Dashboard:** Quick category access to Apartments for Sale, Lands for Sale, and Ongoing Projects.
* **Advanced Buy Module:** Filter through Apartments, Lands, and Buildings seamlessly.
* **Property Listings (Sell):** Easy-to-use form for users to list properties with titles, pricing, area sizes, locations, and descriptions.
* **Development Tracking:** Monitor ongoing construction projects with completion percentages.
* **Investment Opportunities:** Explore high-yield real estate investment projects.
* **Side Navigation Drawer:** Smooth access to profile settings, favorites, user listings, and support.
